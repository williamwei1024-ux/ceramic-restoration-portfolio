# 陶瓷修复作品集 · 线上翻书画册

将《终版修复作品集.pdf》制作为**一本可在浏览器中在线翻阅的书**：有封面、24 页内页、封底，翻页时像真实的书一样翻动、平摊打开。视觉风格与摄影作品集一致：极简杂志风——白底、Playfair Display 细体大标题、Space Mono 数据字体、金色点缀。

封面底纹为**鹦鹉纹枕修复前的线稿**（绿色），封底为**修复后完整文物线稿**（绿色），均从《宋·当阳峪窑三彩鹦鹉枕》页提取绘制，主题绿取三彩釉色。书闭合时左半显示封底内侧书壳。

## 本地预览

```bash
cd 修复陶瓷画册
python3 -m http.server 8080
```

浏览器打开 http://localhost:8080

> 注意：请通过本地 HTTP 服务打开，不要直接双击 `index.html`（`file://` 下浏览器会限制图片加载）。

## 操作方式

- **翻书**：拖拽页面（鼠标或触屏）翻页，如真实翻书
- **下一页 / 上一页**：页面下方按钮，或键盘 `←` `→` / 空格
- **目录**：左上角「目录」，按作品快速跳转，当前作品自动高亮
- **放大查看**：单击页面（内页）放大查看修复细节，`Esc` 关闭
- **封面**：点击封面翻开；翻到末页即为封底

## 自定义

修改 `js/main.js` 顶部的 `CONFIG` 常量即可更新书名、作者与作品目录数据。封面/封底样式在 `index.html` 中由 `js/main.js` 的 `buildCoverPage()` / `buildBackPage()` 生成，改那里即可调整设计。

## 部署

整个目录是纯静态文件（含本地化的翻书库 `js/vendor/page-flip.browser.js`，无需构建），直接拖到 **Netlify Drop** 或 `npx vercel` 即可上线。

## 文件结构

```
修复陶瓷画册/
├── index.html                       # 页面：工具栏 / 书 / 目录 / lightbox
├── css/style.css                    # 极简杂志风样式
├── js/main.js                       # 翻书初始化 / 目录 / 页码 / lightbox
├── js/vendor/page-flip.browser.js   # StPageFlip 翻书库（本地化）
├── pages/p01.jpg…p24.jpg            # 由 PDF 渲染的页面图
└── README.md
```
